# Machine Learning Preprocessing & Models

This project demonstrates a complete Machine Learning workflow, starting with data cleaning and preprocessing, followed by encoding, pipeline creation, and model training.

## Workflow

1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Encoding Categorical Data
5. Creating a Machine Learning Pipeline
6. Decision Tree Model
7. Random Forest Model
8. Model Evaluation

## Machine Learning Models Used

* Decision Tree
* Random Forest

## Preprocessing Techniques

* Data Cleaning
* Missing Value Handling
* Encoding
* `ColumnTransformer`
* `Pipeline`

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

## Project Purpose

The purpose of this project is to understand how data is cleaned and preprocessed before applying Machine Learning models, and to compare Decision Tree and Random Forest models.
